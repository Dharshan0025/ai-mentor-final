# AI Mentor — Innovation Vision
> **Mission:** Not just a smarter ERP. A system that *thinks ahead of the student* — their personal academic life coach, available 24/7, knowing more about their academic health than they do themselves.

---

## Phase 1 — Hyper-Personalization Engine 🎯
> *The system must know the student better than their own parents*

### 1.1 Learning DNA Profile
Every student gets a dynamic **Learning DNA** — a live profile updated after every interaction:

| Dimension | How We Build It | Use Case |
|-----------|----------------|---------|
| **Learning Style** | Track which explanations they click "helpful" on | Visual vs text responses |
| **Peak Study Hours** | From chat timestamps + session activity | Schedule suggestions |
| **Weakness Map** | Topics they ask about repeatedly | Auto-flag for revision |
| **Stress Fingerprint** | Sentiment trend over past 30 days | Early burnout detection |
| **Goal Alignment** | What they say they want vs what data shows | Reality-check coaching |

**Implementation:** New `student_learning_profile` table in Supabase. Updated by agents after each interaction.

### 1.2 Adaptive Response Engine
Agents change HOW they respond based on the student's DNA:

- Student who responds well to analogies → agent uses more analogies
- Student who needs direct answers → no fluff, bullet points only
- Student who's emotionally down → gentler tone, reduce academic pressure in response

## Phase 2 — Proactive Intervention System 🚨
> *The mentor should intervene before the student fails, not after*

### 2.1 Critical Alert Engine (3 Triggers)

```
Trigger 1: Attendance Cliff Warning
  Condition: attendance drops 5% in past 7 days
  Action: push notification + chat message "You need 4 consecutive classes to stay safe"

Trigger 2: Grade Velocity Warning  
  Condition: predicted grade falls below 5.5 (arrear risk)
  Action: immediate study plan generation + parent alert (optional)

Trigger 3: Sentiment Crash Detection
  Condition: sentiment score < -0.6 for 3 consecutive days
  Action: emotional agent initiates check-in WITHOUT student asking
```

**Implementation:** Background job (`apscheduler`) running nightly. Writes alerts to `proactive_alerts` DB table. Frontend polls or uses WebSocket.

### 2.2 "Morning Mission Control" — Daily Briefing Push
Every morning at 8 AM, the system generates a **personalized daily brief**:

```
Good morning Vikram! Here's your mission for today:
🔴 URGENT: OS attendance drops to 68% after yesterday's skip.
   You need to attend ALL 3 today's OS classes.
🟡 EXAM IN 14 DAYS: Your ML score is solid — focus on CN today.
💡 You're at a 5-day streak — don't break it!
```

This isn't just a dashboard card — it's **generated by the AI** using their real numbers.

## Phase 3 — Deep Learning Intelligence 📚
> *Beyond answering questions — actually teaching the student*

### 3.1 Socratic Teaching Mode
When a student asks a question the agent shouldn't just answer — it should **guide them to the answer**:

```
Student: "What is deadlock?"
Current: [Gives explanation directly]
Improved: "Before I explain, tell me — what do you think happens when two processes 
           are waiting for each other forever? Take a guess." 
           → Checks Bloom level → Only then explains at their level
```

### 3.2 Spaced Repetition System
Track *what* each student learns and *when* — then auto-schedule revision:

```
After CS702 session → Log topic "Process Scheduling" with timestamp
7 days later → "Time to revise Process Scheduling! Quick 3-question quiz?"
Just before exam → Auto-generate targeted revision plan for forgotten topics
```

**Implementation:** `topic_mastery` table. `learning_agent` writes to it after teaching sessions.

### 3.3 Past Exam Paper Intelligence
Upload past exam papers to RAG (pgvector already exists!):

```
Student: "What topics come in OS exams?"
Agent: [Retrieves from vectorized past papers]
       "Based on AIHT's past 5 OS exams, deadlocks appears in 4/5,
        page replacement in 3/5, and scheduling in 5/5."
```

## Phase 4 — Life-Skills Mentor 🚀
> *Not just academic — the full student journey*

### 4.1 Placement Intelligence Agent (Upgraded Career Agent)
Current career agent is generic. Upgrade to:

- **Resume Scoring:** "Your resume is missing quantifiable achievements. Add 'Improved X by Y%'"
- **Skill Gap Analysis:** "For TCS Digital, you need DSA Level 4. You're at Level 2."
- **Mock Interview Mode:** Agent asks real interview questions from company-specific patterns
- **Offer Negotiation:** When placement data shows offers, agent helps decide

### 4.2 Peer Benchmarking (Anonymous)
Show the student where they stand — without naming peers:

```
"Your CGPA (7.3) is in the top 35% of CSBS Sem 4 students.
Your attendance (72%) is below the department average (81%).
Students with similar profiles who improved attendance by 10% 
saw an average CGPA increase of 0.3."
```

**Implementation:** Aggregate queries across `students` table. No PII exposed.

### 4.3 Parent Engagement Layer
Optional parent portal:
- Weekly automated report: "Vikram attended 78% this week, up from 65% last week"
- Alerts when arrear risk detected
- Parent can message the AI Mentor for context
