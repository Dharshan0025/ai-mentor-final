# AI System Prompts Collection

A comprehensive collection of system prompts and developer messages from various AI platforms and services.

## Overview

This repository contains documented system prompts from major AI providers, organized by company:

- **Anthropic** - Claude models and related tools
- **Google** - Gemini, NotebookLM, and Workspace AI
- **OpenAI** - ChatGPT, GPT models, and related services
- **Perplexity** - Search and AI assistant prompts
- **xAI** - Grok and related systems
- **Proton** - AI-powered services
- **Misc** - Various other AI platforms

## Structure

Each directory contains markdown files with system prompts and configuration details for different AI models and services.

## Usage

Browse the directories to explore how different AI systems are configured and prompted. This can be useful for:

- Understanding AI system design
- Learning prompt engineering techniques
- Comparing different AI architectures
- Educational and research purposes
